Your daily routine

Three small steps.

Start with the default blocks, or make the schedule yours.

01

Choose a block

Open the app from your system tray. Choose Morning, Afternoon, or Evening, and use the date picker if you are catching up.

02

Write what you did

Use a few words or a short list. Add optional notes for a win, interruption, or lesson. Unfinished drafts stay on your computer.

03

Save and continue

Press Ctrl + Enter or choose Save & continue. Your weekly file updates and the window returns to the tray.

Make reflection easier

A week you can
actually look back on.

Each Monday-to-Sunday week has a single text file. Entries are grouped by date, with a work description for each saved block.

At the end of the week, choose Weekly text in the app. Read it yourself or share it with an AI you choose.

Good to know

Getting started.

How do I install it?

Download DailyJournal.exe, put it in a folder you want to keep, and run it. The app uses Microsoft Edge WebView2; if it is missing, install the WebView2 Runtime. Then open Settings to choose your save folder and reminder times.

Where does my journal go?

Entries are stored on your computer. The default folder is Documents / Daily Journal. Each week has a .txt file for reading and a matching .json file for editing through the app. Keep them together, and edit your entries in the app.

Can I change an entry or fill in a previous day?

Yes. Choose the date and block, then save your changes. Editing replaces that block's entry while keeping the rest of the week.

How do reminders and the tray work?

Closing the window keeps Daily Journal in the tray. Reminders arrive at each enabled block's end time while the app and Windows are running; already saved blocks are skipped. Reminders missed while the computer is off or asleep are not replayed. Use Exit in the tray menu to quit completely.

Is there an account or built-in AI?

The app runs locally and stores your work in your chosen folder. For AI feedback, share the weekly text file yourself with an agent you choose.
