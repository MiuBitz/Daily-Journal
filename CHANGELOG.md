# Changelog

## 1.0.0 - 2026-10-01

- Direct work entry with optional notes and Ctrl + Enter to save.
- One Monday-to-Sunday text file per week, with editable companion JSON data.
- Custom work blocks, optional reminders, historical dates, and local drafts.
- Dark blue default appearance, Inter typography, light mode, and four color presets.
- Reset defaults while preserving the journal folder, saved entries, and drafts.
- Windows tray and startup support.
- One final Windows executable, usage documentation, and a static project webpage.
